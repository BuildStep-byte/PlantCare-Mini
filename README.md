# PlantCare-Mini

Мини-проект на Python для планирования полива домашних растений.

## Что делает скрипт

1. Считывает данные о растениях из CSV-файла (`plants.csv`).
2. Рассчитывает дату следующего полива на основе даты последнего полива и интервала.
3. Вычисляет, сколько дней осталось до полива.
4. Сортирует растения по срочности и выводит понятный план.

## Как запустить

1. Установите зависимости: `pip install pandas`
2. Запустите скрипт: `python main.py`

## Пример вывода
=== План полива === 🌱 Скоро (через 3 дн.) | Папоротник – следующий полив: 2026-11-23 ⏳ Пока спокойно (6 дн.) | Алоказия – следующий полив: 2026-11-26 ⏳ Пока спокойно (6 дн.) | Эпипремнум – следующий полив: 2026-11-26 ⏳ Пока спокойно (9 дн.) | Замиокулькас – следующий полив: 2026-11-29
## Данные

Все данные хранятся в файле `plants.csv`.
